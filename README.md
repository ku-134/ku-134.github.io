# 个人站更新 0.8：

**1. 新增 3D 卡片倾斜特效**  
- 鼠标悬停或手指触摸卡片时，卡片会随光标位置产生立体倾斜（最大 ±8°），模拟真实受压感。  
- 平滑过渡，支持鼠标和触控，无额外性能负担。

**2. 统一应用卡片类**  
所有页面的 `.card` 元素均已添加 `card-3d` 类，特效全局生效。
