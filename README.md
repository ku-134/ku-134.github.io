# 个人站更新 0.9：

**1. 首页智能引导提示**  
- 检测设备为手机或屏幕为竖屏时，自动在页面底部显示非阻塞提示：“💡 推荐使用 电脑横屏 访问”。  
- 提示 4.5 秒后自动消失，不影响用户操作，无需点击确认。

**2. 资源页新增反馈入口**  
- 在 RP 页面底部添加可点击文字：“无法‘拉取分类’或资源等存在问题？点击告知站主。”  
- 点击后弹出独立反馈窗口，清晰展示联系方式（邮件、B站），并强调推荐 B 站评论。  
- 反馈窗口使用与跳转确认相同的毛玻璃风格，交互一致，体验流畅。

**3. 反馈弹窗独立于跳转确认**  
- 不干扰原有资源跳转逻辑，两者互不冲突。
