# 个人站更新 0.7：

**1. 全局打字机 + 下落入场特效**  
- 标题文字（`h1`）现由 JS 拆分为单个字符，依次从上方掉落并淡入，形成打字机效果。  
- 副标题、描述、导航、按钮、页脚等元素按顺序上滑淡入，延迟递增，整体呈现流畅的入场序列。

**2. 新增 `script.js`**  
统一处理打字机逻辑，所有页面共同引用，便于维护。

**3. 样式优化**  
- 新增 `.fade-in-up` 动画类及延迟工具类（`.delay-1` ~ `.delay-8`）。  
- 所有页面文本元素均已应用相应类，实现统一入场效果。
