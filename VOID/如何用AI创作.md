# 如何用 AI 创作

> 从「想」到「做」，AI 是那个帮你把灵感变成现实的伙伴。

## 一、先想清楚：AI 能帮你做什么

AI 创作不是「让机器替你偷懒」，而是**人机协作**。它擅长：

- 📝 **文字**：文章、小说、文案、脚本
- 🎨 **图像**：插画、海报、场景概念图
- 🎵 **音乐**：配乐、音效、歌曲
- 💻 **代码**：网页、小游戏、自动化脚本

而**灵感、审美与判断**，永远是你的主场。

## 二、选对工具

| 领域 | 常用工具 |
| ---- | ---- |
| 文字 | ChatGPT、Claude、DeepSeek、Kimi |
| 图像 | Midjourney、Stable Diffusion、即梦 |
| 音乐 | Suno、Udio |
| 代码 | Claude、Cursor、Copilot |

> 没有最好的工具，只有最适合你的工具——先上手，再比较。

## 三、学会提问（Prompt 的艺术）

好的提示词，是创作成功的一半：

### 万能公式

```
角色 + 任务 + 细节 + 风格 + 约束
```

### 示例对比

❌ 差：`写一个关于花园的故事`

✅ 好：

```
你是一位擅长写童话的作家。请写一个 300 字的小故事：
主角是虚空花园的守梦人，她收集孩子们的梦境。
风格温暖治愈，结尾留白，不要出现悲剧情节。
```

### 小技巧

- 一次只提一个核心需求，别贪多
- 给 AI「示例」比给「形容词」更有效
- 不满意就说「太长了 / 太短了 / 换个风格」，**对话式迭代**才是王道

## 四、迭代与人工介入

AI 的第一版往往是「及格但平庸」的。真正的创作发生在：

1. **筛选**：留下有潜力的部分
2. **修改**：注入自己的风格与细节
3. **整合**：把多段输出拼接成完整作品
4. **打磨**：逐字逐句过一遍，改掉 AI 味

> AI 给你 80 分的基础分，剩下的 20 分，由你的品味决定。

## 五、版权与伦理提醒

- ⚠️ AI 生成内容的版权归属，不同平台规定不同，商用前先查授权
- ⚠️ 涉及他人作品（角色、剧情）时，标注来源、尊重原创
- ⚠️ 不要用 AI 生成虚假信息、侵权内容或伤害他人的文字

## 结语

就像本站一样：90% 由 AI 辅助完成，但**灵魂**永远来自创作者本人。

> 工具会迭代，但好奇心不会过期。
> 愿我们都能用自己的方式，把灵感变成现实。✨
