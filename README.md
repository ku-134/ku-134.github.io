# 个人站更新 0.5：

**1. 弹窗样式移至全局 CSS**  
将 RP.html 中的跳转确认弹窗样式迁移至 `style.css`，利用浏览器缓存进一步提升加载速度。

**2. 资源分类页改为手动拉取**  
进入 RP.html 后不再自动请求 `category.txt`，改为显示“📂 拉取分类”大按钮，用户点击后才拉取并解析展示，减少不必要的初始请求。

**3. 首页新增占位按钮**  
在“我的资源”与“交朋友”之间新增“我的文章”和“我的游戏”按钮（暂不跳转），为后续功能预留入口。

**4. RP 导航栏更新**  
资源分类页导航栏调整为“首页 · 资源 · 玩点游戏？”，其中“资源”为当前激活页，“玩点游戏？”占位待用。
