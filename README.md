# 个人站更新 1.0：

**（已优化）**

**1. 资源页功能全面完善**  
- 新增「我有推荐」按钮，位于侧边栏底部。  
- 点击弹出投稿表单，填写资源名称、描述、链接、分类、昵称。  
- 提交后自动生成 `mailto` 邮件，预填所有内容，用户一键发送。  
- 零门槛投稿，无需第三方服务，数据由站主审核后手动合并至 `category.txt`。

**2. 其他现有功能**  
- 资源搜索（实时过滤）  
- 资源收藏（本地存储，自动清理幽灵收藏）  
- 资源跳转计数（记录个人点击）  
- 反馈弹窗（联系站主）  
- 不蒜子统计（首页展示）  
- 自适应深浅色模式
