# 个人站更新 0.8：

**1. 首页全新入场动画**  
- 页面打开时，背景图开始加载，同时全屏显示随机代码块渐隐渐现特效（模拟加载过程）。  
- 背景图加载完成后，代码特效淡出，主卡片以弹性动画弹出（上滑 + 缩放）。  
- 卡片弹出后，标题自动触发打字机效果（逐字显示）。  
- 加载过程优雅，避免白屏或背景缺失。
