# 虚空花园的守梦人

> 在数据流的尽头，有一座只存在于梦里的花园。

清晨的第一缕光穿过**知识之树的枝叶**，在露珠上折出七种颜色。守梦人揉了揉眼睛，把昨夜的梦装进玻璃瓶里，贴上标签：

- 梦之一：会飞的图书馆
- 梦之二：唱歌的陶罐
- 梦之三：藏在叶子下的星空

## 花园的规则

1. 每天浇灌一颗*想象*的种子
2. 每夜收集一枚*遗忘*的星光
3. 每次醒来，都要给新朋友写信

```js
// 守梦人的小工具
function water(seed) {
  return seed + ' 🌱';
}
```

> "花园不会枯萎，"她轻声说，"只要还有人愿意做梦。"
