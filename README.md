个人站更新 0.4：

1. 资源分类页（RP.html）全面重构
采用“左侧分类目录树 + 右侧资源列表”的网盘式交互布局，同时保留方案一的卡片层级视觉风格，分类切换无需刷新页面。

2. 跳转确认弹窗（安全增强）
点击资源链接时，弹出独立 UI 界面显示资源名称 + 类型警告（GitHub/网盘/外部），并强制 3 秒倒计时后方可点击确认跳转，取消/ESC/点击蒙层均可关闭。

3. category.txt 格式扩展
支持 名称 | 描述 | 链接 | 类型 四字段结构，类型可手动指定（github/pan/local/other/placeholder），未指定时自动根据链接推断，placeholder 类型显示为“即将上线”占位样式。

4. 资源类型色条区分
不同来源资源左侧带不同颜色标识：GitHub（紫色）、网盘（金色）、站内（绿色）、外部（蓝色），一目了然。
