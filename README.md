# 📖 关于本站

**虚空终端** 是一个以优质（主观）资源归档与轻量级网页应用为核心内容的**个人数字项目（迫真）**。本站致力于在信息过载的网络环境中，筛选并呈现经过实测、分类的实用工具与趣味内容，为访客提供高效、透明、无干扰的浏览体验。

## ✨ 站点定位

| 关键词 | 说明 |
| ------ | ---- |
| 🧩 资源归档 | 收录经实测可用的开源应用、效率工具与 PC 游戏 |
| 🎮 轻量应用 | AI 辅助生成的网页游戏与交互小工具 |
| ✍️ 同人创作 | 原创小说、角色扮演（RP）内容 |


## 🔄 更新策略

本站遵循 **“随缘更新，随缘维护”** 的节奏（我懒），不设固定排期，但所有已上线内容均保证链接有效与信息准确。重要更新会通过首页公告或独立日志告知访客。

# 📂 内容架构

当前终端开放三个主要板块：

### 一、资源库 📦

收录经实测可用的开源应用程序、效率工具及 PC 端游戏。所有条目均附带简要说明，并支持关键词搜索与分类筛选。

### 二、游戏合集 🎮

汇集由 AI 辅助生成的网页游戏作品，包括本站自主构思开发的原创游戏，以及其他作者标注来源的公开作品。

> 我是尊重原创的——如果我的引用给你带来不满，请如实告知，我会删除相关文件代码。

### 三、文章板块 📝

基于 Markdown 的轻量文章系统（`VOID.html`），正文存放于 `VOID/` 目录，由 `index.txt` 索引驱动：

- **Markdown 渲染**：`index.txt` 索引 + `VOID/` 目录存放正文
- **自定义标题与简介**：`文件名.md -标题 | 简介`
- **系列连载**：自动识别「名1.md」编号（静态探测，无速率限制），详情页生成翻页条与目录跳转
- **收藏置顶**：列表页加星，收藏文章前排展示，首页「我的数据」实时计数
- **排序切换**：按标签 ↹ 按字母，摆脱登记顺序混乱
- **阅读统计**：跳转详情页自动计数，首页展示涨幅
- **隐藏文章**：`#` 前缀标记，连续点击标题 5 次 → 输入口令解锁（24 小时有效）

### 四、工具板块 🛠️

公开网页工具合集页（`MT.html`），当前收录 5 个工具（`tool/` 目录）：

| 工具 | 说明 |
| ---- | ---- |
| 📊 设备信息 | 读取屏幕、浏览器、网络、电池、GPU 等设备信息 |
| 🔐 权限请求 | 查询并测试地理位置、摄像头、麦克风等浏览器权限 |
| 🕵️ 追踪检查 | 按优先级列出浏览器隐私泄露点并实时检测 |
| 🗜️ 图片压缩 | 选择文件、压缩、下载，本地处理图片压缩 |
| 📡 P2P 传输 | 创建 4 位号码互相连接，文件经 WebRTC 点对点直传 |

- 卡片展示由 `tool/index.txt` 索引驱动（行首 emoji + 名称 + 简介）
- 支持关键词搜索与收藏置顶，全部本地处理
- 权限类工具在 via 等 WebView 浏览器中可能不兼容（已注明）

# 🔧 使用指南

### 快速开始

```bash
# 克隆仓库
git clone https://github.com/ku-134/ku-134.github.io.git

# 本地预览（任选其一）
python3 -m http.server 8080   # Python
npx serve                     # Node.js
```

### 发布文章

1. 将正文 Markdown 文件放入 `VOID/` 目录；
2. 在 `VOID/index.txt` 中登记一行：

```
测试文本.md -我的标题 | 这是一段简介
# 隐藏文章.md -秘密 | 只有解锁后才能看到
```

3. 推送 `main` 分支，GitHub Pages 自动发布。

### 隐藏文章口令

连续点击文章页标题 5 次，输入口令即可解锁（有效期 24 小时）。口令是什么？……这是个秘密 🤫
