# 个人站更新 0.99：

**1. 资源页新增搜索功能**  
- 实时搜索资源名称和描述，匹配结果即时刷新。  
- 搜索框带清空按钮，支持防抖优化。

**2. 资源页新增收藏功能**  
- 每个资源右侧可点击星标 ☆/★ 进行收藏/取消收藏。  
- 收藏数据保存在浏览器本地，刷新不丢失。  
- 左侧目录新增“⭐ 我的收藏”分类，点击仅显示已收藏资源。  
- 收藏的资源卡片带有金色边框高亮。

**3. 首页新增访客足迹功能**  
- 每次进入或刷新首页，自动显示欢迎语。  
- 首次访问显示“👋 欢迎首次访问！”  
- 非首次访问显示“👋 欢迎回来，上次访问是 X 天前”。  
- 独立 Toast，与横屏推荐提示互不冲突，位置错开。

**4. 交互优化**  
- 搜索和收藏功能与原有分类、拉取逻辑无缝集成。  
- 所有弹窗（跳转确认、反馈、收藏）风格统一。  
- 完美适配移动端和桌面端。
