# 如何用 AI 创作

> 从「想」到「做」，AI 是那个帮你把灵感变成现实的伙伴。


## 一、先想清楚：AI 能帮你做什么

AI 创作不是「让机器替你偷懒」，而是**人机协作**。它擅长：

- 📝 **文字**：文章、小说、文案、脚本
- 🎨 **图像**：插画、海报、场景概念图
- 🎵 **音乐**：配乐、音效、歌曲
- 💻 **代码**：网页、小游戏、自动化脚本

而**灵感、审美与判断**，永远是你的主场。

以 DeepSeek 为例：它相当于一个读过三亿本书、通晓编程语言的超级实习生。但如果你把它当许愿池，它就只能给王八级别的答案——关键在于你如何「下指令」。

## 三、学会提问（Prompt 的艺术）

好的提示词，是创作成功的一半。

### 核心公式

```
角色 + 任务 + 细节 + 风格 + 约束
```

### 示例对比

❌ 差：`写一个关于花园的故事`

✅ 好：

```
你是一位擅长写童话的作家。请写一个 300 字的小故事：
主角是虚空花园的守梦人，她收集孩子们的梦境。
风格温暖治愈，结尾留白，不要出现悲剧情节。
```

### 进阶框架：CRISPE（相当于跟 AI 签一份创作合同）

| 要素 | 含义 | 好例子 |
|------|------|--------|
| **C**-角色 | 让 AI 扮演谁 | “你是擅长余华式冷静笔调的作家” |
| **R**-请求 | 具体任务 | “续写本章 3000 字，包含一个身世反转” |
| **I**-背景 | 上下文信息 | 附上前文人设、世界观大纲 |
| **S**-要求 | 明确限制 | “禁止现代词汇，每段对话不超过三行” |
| **P**-风格 | 语气文风 | “像朋友聊天，别端着，多用短句” |
| **E**-尝试 | 多个版本 | “请提供三个不同的剧情走向” |

### 小技巧

- 一次只提一个核心需求，别贪多
- 给 AI「示例」比给「形容词」更有效
- 不满意就说「太长了 / 太短了 / 换个风格」，**对话式迭代**才是王道
- 实在不知道让 AI 扮演什么角色？让它自己推荐三个选项，你来挑


## 四、分场景实战

### 📖 写小说：分层搭建

**不要一次性让 AI 写全文**，正确流程是逐层推进：

**第一层：世界观设定**
```
生成东方仙侠世界观：九州四海结构，凝气→化神→返虚三境界，
核心矛盾是仙魔通道意外开启。
```

**第二层：人物设计**
```
主角：外冷内热，矛盾点是守护宗门 vs 保护妖族恋人，
成长弧线：从绝对正义到理解灰色地带。
```

**第三层：情节推进**
```
虐恋线：相遇→家族世仇→三次关键冲突→HE结局。
```

**第四层：细节描写**
```
暴雨夜告白场景，昏黄路灯，侧重心理描写。
```

每一层确认满意后再进入下一层，最后逐章生成、人工润色。

### 💻 写代码：结构化生成

**万能提示词模板**：
```
你是一位拥有 10 年经验的资深工程师。
请审查/实现以下代码：[粘贴代码或描述需求]
系统日均 QPS 为 10 万，对延迟敏感。
重点关注性能、安全问题。
给出 3 种方案并对比优缺点。
```

**进阶技巧**：
- **Few-shot**：给 2-3 个示例，让 AI 快速理解你的代码风格和模式
- **思维链**：让 AI 一步步思考——“先设计数据结构，再实现方法，最后展示完整代码”
- **调试**：遇到 bug 直接把报错信息贴给 AI，说“帮我修复”

实测数据：在复杂编程任务中，结构化提示可使准确率从 68% 提升至 91%。


## 五、迭代与人工介入

AI 的第一版往往是「及格但平庸」的。真正的创作发生在：

1. **筛选**：留下有潜力的部分
2. **修改**：注入自己的风格与细节
3. **整合**：把多段输出拼接成完整作品
4. **打磨**：逐字逐句过一遍，改掉 AI 味

> AI 给你 80 分的基础分，剩下的 20 分，由你的品味决定。


## 六、常见问题

**Q：回答太水太泛怎么办？**
用 CRISPE 框架重写提示词，明确角色、细节和约束。

**Q：前后矛盾怎么办？**
DeepSeek 有百万 Token 上下文，把前文、人物卡、世界观全部放在对话开头。写长篇时，关键信息要反复「提醒」。

**Q：回答中断了怎么办？**
输入 `/续写`，AI 会自动继续。

**Q：代码有 bug 怎么办？**
把错误信息复制给 AI，说“这段代码报了这个错，帮我修复”。

**Q：API 免费额度用完了怎么办？**
切回网页版（完全免费无限用），或申请教育优惠、参与开源贡献换取额度。


## 七、版权与伦理提醒

- ⚠️ AI 生成内容的版权归属，不同平台规定不同，商用前先查授权
- ⚠️ 涉及他人作品（角色、剧情）时，标注来源、尊重原创
- ⚠️ 不要用 AI 生成虚假信息、侵权内容或伤害他人的文字


## 结语

就像这篇文章一样：AI 辅助完成了结构和初稿，但**灵魂**——观点的取舍、案例的选择、语言的温度——来自创作者本人。

AI 不会取代创作者，但会用 AI 的创作者，一定会取代不用 AI 的。

> 工具会迭代，但好奇心不会过期。
> 愿我们都能用自己的方式，把灵感变成现实。✨
