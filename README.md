# 个人站更新 0.999（某夕式-版本号）：

**1. 全站接入不蒜子统计**  
所有页面均已接入不蒜子（Busuanzi）统计服务，自动统计独立访客（UV）和总访问量（PV）。

**2. 首页新增数据展示卡片**  
在首页描述下方增加统计卡片，美观展示全站独立访客和总访问量数据，与毛玻璃风格完美融合。

**3. 其他页面底部统计**  
关于页、联系页、资源页底部均显示统计信息，方便访客了解本站热度。

**4. 接入方式**  
无需注册、无需配置，插入一行 JS 脚本和两个标签即可使用，数据托管于国内 CDN。
